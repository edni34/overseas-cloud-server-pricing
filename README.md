## 海外云服务器购买先看哪几个参数？

先看地域和线路，再看带宽与流量计费，最后核对续费价和退款政策。配置放到后面，因为一台 2 核 4G 的机器如果线路绕、流量贵，实际体验可能还不如配置低一档但线路合适的方案。

| 判断项 | 具体要问什么 | 常见坑 |
| --- | --- | --- |
| 地域与用户位置 | 用户主要在哪，选最近的数据中心 | 只看“美国”不够，美国东岸和西岸延迟差很多 |
| 线路 | 是否 CN2、CN2 GIA、BGP、日本软银等优化线路 | 普通国际线路晚高峰可能绕路，页面不一定写清 |
| 带宽与流量 | 独享带宽、峰值带宽、月流量包、超量单价 | “无限流量”常有限速或公平使用规则 |
| 计费周期 | 月付、年付、按小时计费 | 年付低价可能只限首期，续费价另算 |
| 续费与退款 | 续费价、退款天数、是否免费换 IP | 首期便宜不等于长期便宜 |

线路这块，公开测评里经常被拿来比较的是萤光云和 LightNode 的 CN2 或优化线路，Hostwinds 则主打美国大带宽和免费换 IP。萤光云目前标出的政策包括 **5 天无理由退款** 和 **2 次免费更换 IP**；LightNode 支持按小时计费，用多少扣多少，适合短期开机测试。这些政策比单纯看“2 核 4G 多少钱”更影响实际使用成本。

带宽和流量是第二个容易忽略的地方。轻量应用服务器通常给一个月流量包，超出后限速或按量收费；CVM 这类云服务器则把带宽和流量拆开计价。买之前把“月流量用完后怎么收费”翻出来看一眼，比事后补账单便宜。

## 常见问题

**海外云服务器购买需要备案吗？**
通常不需要 ICP 备案。服务器在境外或中国香港，网站不用走大陆备案流程；但域名、内容、隐私政策、支付和税务合规仍要自己处理。

**中国香港、新加坡、美国怎么选？**
用户在哪选哪。中国大陆用户多、又想兼顾低延迟，中国香港和新加坡通常比美国西海岸更稳；欧美用户直接选当地节点。具体还要看服务商是否提供 CN2 等优化线路。

**月付还是年付？**
短期测试选月付或按量计费，长期生产再考虑年付。年付之前先看续费价和退款政策，避免首年便宜、续费翻倍。

**2 核 2G 够用吗？**
个人站、小 API、测试环境通常够用。WooCommerce、数据库、生产 API 建议从 2 核 4G 起，具体看并发和内存占用。

**为什么同配置价格差很多？**
带宽是独享还是峰值、有没有 CN2 线路、月流量多少、IP 是否免费更换、是否超售、续费价多少，都会影响价格。只看 CPU 和内存容易误判。
